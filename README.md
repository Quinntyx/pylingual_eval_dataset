# Pylingual Evaluation Dataset
This is the dataset that was used in the original [Pylingual Paper](https://ieeexplore.ieee.org/document/11023256) and has been extended to include newer releases of Python.

##  Usage

```
uv run eval <version text file> <output director>
```
